How discovery works

Website discovery uses the configured location, price, area and bedroom filters, newest first. It stops at a page of known listings (up to 20 pages). Each new listing still gets the same full detail fetch and AI facts extraction. This is an incremental scan, not a complete inventory: older newly matching listings can be missed, and website markup changes or bot challenges can interrupt it.
